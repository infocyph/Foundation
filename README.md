# Foundation

Foundation is the core PHP library behind [Infbyte](https://github.com/infocyph/Infbyte), providing application composition, lifecycle, and integration with native Infocyph components.

## Installation

Requires PHP 8.4 or newer.

```bash
composer require infocyph/foundation
```

For application development, use the [Infbyte starter](https://github.com/infocyph/Infbyte).
