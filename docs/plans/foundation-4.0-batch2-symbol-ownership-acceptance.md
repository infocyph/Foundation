# Foundation 4.0 — Batch 2 production-symbol responsibility acceptance

**Acceptance date:** 2026-10-14. **Source:** `994c1e3624f92a77aa6b029c80ac166decef4e82`. **Evidence:** [Security & Standards #38491340356](https://github.com/infocyph/Foundation/actions/runs/38491340356) — complete success. **Batch 2: 8/8; overall 14/37.** PR #20 remains draft and unmerged.

## Scope and inspection standard

The nontruncated source tree includes **654 PHP files under `src/`**, compared with the original dated 662-file census. `NativeProductionSymbolOwnerInventoryTest` walks **all** current PHP files with PHP's tokenizer, identifies named types (classes, interfaces, traits, enums), named functions and methods, checks duplicate types and missing declarations, and assigns every declaration a required Foundation responsibility or native-package boundary. There are **31 top-level areas** and **32 more granular source responsibility prefixes** for the large auth, HTTP and configuration families. Adding an unmapped source area or dropping a configured responsibility family fails this test; counts are not falsely frozen to the initial number of files.

A public/protected declaration is an intentional framework or integration contract; lack of an in-repository static caller **alone** is not authority to delete it. `NativePrivateMethodUseTest` scans for ordinary unreferenced production-private methods, except magic entrypoints and trait methods that may be called in consuming classes. `NativeInternalSymbolReachabilityTest` requires nonlocal production references for internal ownership classes and graph factories. These scanners detect candidate orphan code but are **not mathematical proof of reachability under arbitrary reflection or user-selected external code**. `LegacyRuntimePathBoundaryTest` forbids known retired codepaths. Those limitations are accounted for by preserving deliberate public extension seams and adding executable integration/regression coverage at native boundaries.

## Explicit retain, delegate, and remove decisions

| Responsibility | Native owner; retained Foundation role | Disposition |
| --- | --- | --- |
| InterMix service graphs, compiled release, DI scopes | InterMix 11.2 owns graph/ABI; Foundation owns capability selection, immutable release identity and execution-specific lifecycle | **Retain application composition**, delegate container/scoping |
| HTTP routing and matching | Webrick 6.0.3 owns router/matchers/emission; Foundation owns route declarations, middleware policy, signed-key selection and release orchestration | **Delegate engine**, retain policy |
| Cache/locks/counters/outbox | CacheLayer 4 owns data structures and atomicity; Foundation owns store identity, cache policy, topology validation and DBLayer hookup | **Delegate engine**, retain policy |
| Database connection/query/migration mechanisms | DBLayer 6.1 owns execution and client semantics; Foundation owns configured topology, authenticated repositories and execution cleanup | **Delegate engine**, retain application ownership |
| Authentication and identity | Epicrypt / OTP / WebAuthn own cryptographic/protocol ceremony; Foundation owns accounts, consent, persistence mapping, selected drivers, principal precedence, policy/HTTP presentation | **Retain policy and adapters** |
| Browser sessions | Native Webrick request/InterMix scope and CacheLayer/DBLayer state; Foundation owns cookie/flash/CSRF and its distinct account-auth session mapping | **Retain distinct application contracts** |
| Communication, messaging and validation | TalkingBytes, Omnibus and ReqShield own protocol and transport/schema primitives; Foundation owns configured profiles, replay protection, dispatch maps, application schema extensions | **Retain selection and translation only** |
| Filesystem | Pathwise owns transfer/storage mechanics; Foundation owns selected disk, malware/trust profile and Webrick response mapping | **Retain policy and transport boundary** |
| Worker/process/scheduler/CLI | Native Omnibus/Runwire runtime mechanisms own host supervision; Foundation owns application subprocess command and scheduled-job policy | **Retain bounded application control**; native host propagation awaits Batch 3 |
| Outer trusted generations and configuration | ArrayKit, InterMix and Webrick own native artifacts; Foundation owns outer generation publication, identity, deployment and application config | **Retain trust/lifecycle composition** |

**Eight obsolete standalone source owners removed:** `DatabaseGraphFactory`, `NotificationGraphFactory`, `AuthRuntimeGraphFactory`, `AuthStoreGraphFactory`, `AuthNotificationGraphFactory`, `FilesystemGraphFactory`, `WebrickRuntimeFactory`, and `RuntimeModeFactory`. They were stateless forwarding classes, not independent feature contracts. Static InterMix recipes now live on owning providers/registrars; the runtime-mode recipe calls PHP's native backed enum directly. `NativeFactoryOwnershipTest`, `AuthNativeRegistrarRecipeTest`, `NativeNotificationOwnerTest`, and `FoundationGraphTest` lock the direct contracts and compiled/development parity.

**Retained nontrivial helpers are not duplicate native engines:** `AuthHttpGraphFactory` selects authentication principal resolvers and OAuth priority; `AuthMfaGraphFactory` applies OTP replay and key policy; `AuthPasskeyGraphFactory` enforces ceremony-cache interface selection; `AuthPersonalAccessTokenGraphFactory` resolves purpose-bound signing keys; `CacheGraphFactory` enforces the optional database topology; `SessionGraphFactory` guards browser session configuration; `MessagingGraphFactory` maps application routes/handlers into Omnibus; `CommunicationGraphFactory` configures inbound gRPC and webhook replay; `ValidationGraphFactory` freezes configured ReqShield schemas; `SecurityGraphFactory` validates Epicrypt password options; `HttpRuntimeFactory` composes Webrick handlers with framework exception reporting. Named runtime resolvers, persistence stores, provider registrars and user-facing interfaces likewise retain application responsibility rather than a second native engine.
